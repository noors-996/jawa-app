# مساعد جاوا 🫒

تطبيق باسم المعصرة بتفتحه من الموبايل وبيعمل التالي:
- **المساعد**: بتحكي معه عادي، فبيشوفلك الرسائل والتعليقات ويجهز ردود. الرد ما بينبعت إلا لما تكبس **موافق**.
- **الجدول**: بترفع صورة أو فيديو، وهو بيكتبلك الكابشن، وبتختار متى ينزل. إذا ما اخترت وقت، بياخد أقرب موعد فاضي من مواعيدك.
- **التنبيهات**: الزباين اللي بدهم إياك شخصياً، ونتيجة النشر والرد التلقائي.
- **الإعدادات**: مواعيد النشر، وعدد البوستات باليوم، والرد التلقائي (مطفي من الأساس).

إذا انستغرام طلب تحقق أو تسجيل دخول، التطبيق بيوقف النشر والردود لحاله وبيطلعلك تنبيه.

---

## التشغيل

### 1) جيب المفاتيح
| الشي | من وين |
|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com ← API Keys، وحط رصيد بالحساب |
| `COMPOSIO_API_KEY` | composio.dev ← Settings ← API Keys |
| `COMPOSIO_CONNECTED_ACCOUNT_ID` | composio.dev ← Connected Accounts ← حساب jawapress الشغال (الجديد). الرقم بيبلش بـ `ca_` |

### 2) ارفعه على سيرفر
أسهل طريق **Railway** أو **Render**، والتنين بيشغلوا الـ Dockerfile لحالهم:
1. ارفع هالمجلد على GitHub (repo خاص).
2. اعمل مشروع جديد من الـ repo.
3. زيد **Volume** على المسار `/data`. هون بتنحفظ الصور والجدول والإعدادات، وبدونه بيضيعوا كل ما السيرفر يعيد التشغيل.
4. حط المتغيرات اللي بملف `.env.example` بالـ Variables.
5. خذ الرابط اللي بيعطيك ياه (https://…) وحطه بـ `PUBLIC_BASE_URL`. انستغرام بيسحب الصور منه وقت النشر.

أو على أي سيرفر عندك فيه Docker:
```
cp .env.example .env   # عبّي القيم
docker build -t jawa-app .
docker run -d --restart always --env-file .env -p 8000:8000 -v jawa-data:/data jawa-app
```
بس لازم يكون عليه دومين وhttps.

### 3) حطه على الموبايل
افتح الرابط وسجل دخول بكلمة السر:
- **آيفون**: Safari ← زر المشاركة ← Add to Home Screen
- **أندرويد**: Chrome ← ⋮ ← Install app / Add to Home screen

بيطلع أيقونة باسم التطبيق متل أي تطبيق عادي.

## ملاحظات مهمة
- **جرّب أول بـ `DEMO_MODE=1`**: التطبيق بيشتغل ببيانات وهمية وما بيلمس الحساب الحقيقي.
- **الرد التلقائي**: إذا شغلته من الإعدادات، **طفّي المهمة المجدولة القديمة** على Claude عشان ما ينرد على الزبون مرتين. بيرد بس على أسئلة السعر والموقع والدوام والطلب، وأكثر إشي 4 ردود بكل مرة، وبين كل رد ورد دقيقة لدقيقتين ونص.
- **الأسعار** ما بتنكتب بالتعليقات أبداً، بس بالخاص.
- **الفيديو** لازم يكون MP4، والصور JPG أو PNG.
- **التكلفة**: بتدفع لـ Anthropic حسب الاستعمال. إذا بدك توفر، فبتقدر تحط `MODEL=claude-haiku-5-5`.
- اسم التطبيق بتغيره من `APP_NAME`.
